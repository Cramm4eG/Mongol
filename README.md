# Контроль контрагентов

Простое веб-приложение для двух сотрудников небольшого бизнеса.  
Позволяет быстро проверять, разрешена ли конкретному контрагенту покупка товара в долг.

**Главные возможности:**
- Общий список контрагентов в реальном времени
- Статусы: 🟢 ЗАКУП РАЗРЕШЁН / 🔴 ЗАКУП ЗАПРЕЩЁН
- История всех действий с указанием сотрудника и времени (часовой пояс Asia/Bishkek)
- Работает на компьютере и смартфоне через браузер
- Авторизация по email + пароль
- Безопасный доступ (Row Level Security)

## Быстрый старт (кратко)

1. Создайте проект в [Supabase](https://supabase.com).
2. Выполните содержимое файла `schema.sql` в SQL Editor.
3. Создайте двух пользователей в Authentication → Users.
4. Отключите публичную регистрацию (Authentication → Providers → Email → отключите "Enable sign ups").
5. Скопируйте Project URL и anon key.
6. Вставьте их в `index.html` (в конце файла, в теге `<script>`).
7. Загрузите проект на Cloudflare Pages (через GitHub или прямую загрузку).

**Полная пошаговая инструкция для новичков** — в файле [DEPLOYMENT.md](DEPLOYMENT.md).

## Безопасность

- Публичная регистрация отключена.
- Доступ только у авторизованных пользователей.
- Все операции изменения данных выполняются через SECURITY DEFINER функции.
- Прямые INSERT/UPDATE/DELETE на таблицы запрещены политиками RLS.
- История действий (audit_log) недоступна для редактирования и удаления обычным пользователям.
- Секретный `service_role` ключ **никогда** не попадает во frontend.

## Что умеет приложение

- Вход по email и паролю
- Добавление контрагента (начальный статус — разрешён)
- Переключение статуса с обязательным подтверждением
- Поиск по названию (без учёта регистра)
- Фильтр: Все / Разрешён / Запрещён
- Сортировка по названию и дате изменения
- Переименование
- Архивирование (мягкое удаление) — история сохраняется
- История действий в реальном времени
- Синхронизация между устройствами без перезагрузки
- Адаптивный интерфейс для телефона
